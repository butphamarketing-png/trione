# TRIONE.VN Demo

Demo website chương trình **thu cũ đổi mới đồng hồ** theo đặc tả, hợp đồng và bộ giao diện TRIONE.

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000) hoặc bản online [https://trione-umber.vercel.app](https://trione-umber.vercel.app).

**Hướng dẫn thao tác:** xem [HUONG-DAN.md](./HUONG-DAN.md).

| Cổng | Đường dẫn |
|---|---|
| Wizard khách 9 bước | `/thu-cu` |
| Đăng nhập | `/dang-nhap` (`nv.anh` · `sala.hcm` · `admin` / `123456`) |
| Nhân viên | `/nhan-vien` |
| Admin CMS | `/admin` |

Giá thu cũ demo: lấy **loại xấu nhất** từ chức năng / màn hình / thân máy / pin / dây đeo. Không hoạt động = loại 5.
